# Кастомизация «О устройстве» на Android 16

В списке твиков приложения «Настройки» доступны три независимых хука:

- **Динамический градиент «О устройстве»**: заменяет зашитый фон под фото.
  Цвета вычисляются по трём областям нижней части показанного изображения,
  затем плавно уходят в прозрачность, оставляя фон текущей темы.
  Работает и со штатным изображением, и с выбранным через хук картинки.
- **Редактор «О устройстве»**: отдельное меню для изменения подписи и значения
  штатных пунктов, их скрытия, добавления собственных пунктов и изменения
  порядка собственных строк. Название модели под логотипом настраивается
  отдельно от строки «Имя устройства».
- **Скрыть разделители «О устройстве»**: скрывает `VDivider` между группами
  и линии внутри `VivoDeviceInfoLayout`, включая добавленные строки.

После изменения настроек закройте системное приложение «Настройки» через
force stop и откройте экран заново. Все новые хуки по умолчанию выключены.
Кастомизация меняет представление этого экрана; системные свойства, данные
об оборудовании и имя устройства для Bluetooth не записываются.

У штатных пунктов можно независимо переопределить подпись и значение.
«Как в прошивке» сохраняет штатную видимость, «Скрывать» убирает пункт,
«Показывать» отображает его, даже если прошивка не создаёт его для модели.
В последнем случае укажите своё значение: аппаратный контроллер недоступного
чипа не запускается. Сброс отдельного пункта возвращает штатное поведение.
Сброс всего редактора также удаляет собственные строки.

## Точки перехвата, проверенные в APK «Настройки 16.0»

- `VivoAboutPhoneFragment.onCreateView()` / `onConfigurationChanged()` —
  заполнение страницы и добавление строк в вертикальный
  `about_phone_device_info_layout`, после аккумулятора и перед нижними ссылками.
- `VivoDeviceInfoBaseController.initRootView(View)` и реализации
  `getSummary()` / `bindView(View)` — переопределение существующих строк,
  включая последующее обновление имени в `onResume()`.
- `VivoDeviceInfoProductModelController` — подпись под логотипом;
  для собственного названия скрывается отдельная штатная картинка iQOO.
- `theme.VivoDeviceInfoOriginImageController.bindView(View)` — замена drawable
  у `origin_logo_image_bg` с сохранением его исходных размеров. Штатный
  контроллер продолжает рассчитывать размеры фона и отступы страницы.
- `VivoDeviceInfoLayout.setDividerVisibility(boolean)` и создание строки —
  скрытие внутренних линий. Обход элементов ограничен экраном «О устройстве».

Редактор сохраняется одной JSON-записью в настройках модуля, синхронизируемой
через RemotePreferences. Процесс настроек перечитывает конфигурацию при
обновлении страницы; повреждённая запись возвращает штатные значения.

Регистрация и применение новых хуков ограничены Android 16 и выше через
`ro.build.version.release`. Проверка компиляции выполняется в GitHub Actions;
работу интерфейса нужно проверять на устройстве с этой сборкой настроек.
