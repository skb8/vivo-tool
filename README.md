# Vivo Tool

Xposed / LSPosed модуль для устройств **Vivo** и **iQOO**, адаптированный под **OriginOS 5** (Android 15).

## Требования

- **ОС:** OriginOS 5 (Android 15)
- **Устройства:** Vivo и iQOO
- **Фреймворк:** LSPosed (Xposed API 93+)

## Установка

1. Установите APK модуля из [Releases](../../releases).
2. Включите модуль в LSPosed и выберите рекомендуемые приложения в области действия (scope).
3. Выполните мягкую перезагрузку (Soft Reboot) или перезапустите целевые приложения.
